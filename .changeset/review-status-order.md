Order pull requests by review status. Your pull requests are grouped as changes requested, approved, reviewed, awaiting review and drafts; review requests as needing your review, reviewed by you and drafts, newest activity first within each group. Your own pull requests no longer appear under review requests, even when they are assigned to you. Pull requests load through one GitHub GraphQL search per list, which also reads the latest reviews of busy pull requests correctly. Seen state starts over once after the update.
