Show stacked pull requests together. A pull request whose base branch is another's branch in the same repository joins its stack. A stack has its own header: the branch it merges into, how many pull requests it holds, and how many are at each status. Its members sit indented below, top first, on a line through each one's status. Click the header to fold the stack; the panel remembers it. A stack sits in the section of its most urgent member.
