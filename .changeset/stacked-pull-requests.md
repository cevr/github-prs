Show stacked pull requests together. A pull request whose base branch is another's branch in the same repository joins its stack. Each stack is its own section, ahead of the status sections. Its heading shows the title of the stack's first pull request, the repository, how many pull requests it holds, the branch it merges into, and how many are at each status. Its members follow, top first, on a line through each one's status. Click the heading to fold the stack; the panel remembers it. The stack with the most urgent member comes first.
